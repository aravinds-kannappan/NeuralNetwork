# Already-clean audit · What survives as a neuron learns?

An independent computational reproduction of selected results from [Abay Bektursun’s already-clean audit](https://github.com/abaybektursun/already-clean-audit), extended with sentence embeddings, cosine similarity, lexical controls, and statistical sensitivity checks.

**[Read the beginner-friendly interactive report →](https://aravinds-kannappan.github.io/NeuralNetwork/already-clean/)**

[Download the standalone HTML report](https://aravinds-kannappan.github.io/NeuralNetwork/already-clean/downloads/beginner-report.html) to read it offline.

This separate study folder contains the complete checkpoint analysis. It includes the source, 56 hash-verified upstream inputs, locked dependencies, all three completed runs, five saved embedding matrices, analysis plans, provenance, and the full report.

## Main finding and its limits

After removing repeated contexts, late-checkpoint examples are more similar to the same neuron’s final examples than to other neurons in its layer: **+0.176 cosine**, 95% layer-bootstrap interval **[0.091, 0.293]**, from 13 eligible neurons in nine layers. This is exploratory evidence about selected text in **one original OLMo training run**, not proof of a persistent causal mechanism. The stricter random-only identity test has only 16 assignments and gives **p = 0.0625**.

The accessible one-job counts and parent-test arithmetic reproduce. **Reproducing arithmetic is not validating every interpretation:** Abay retracted the “main cluster is oldest” interpretation after a better random-group control. The report and website preserve that correction, alongside the parent test’s control-calibration sensitivity.

## Reproduce the analysis (from the repository root)

Python 3.12 and [uv](https://docs.astral.sh/uv/) are required by the locked recipe. CPU execution is sufficient. The first run downloads the two pinned sentence encoders. This reanalyzes published measurements; it does not rerun OLMo inference or the original private judges and interventions.

```sh
cd studies/already-clean
uv run --locked python reproduce_all.py --output ./outputs
uv run --locked python -m unittest already_clean_reproduction.test_statistics
```

Choose a fresh output directory for each rerun. The runner restores its temporary configuration changes even if a phase fails. The saved original results remain under `runs/`.

## Build and preview the website (from the repository root)

The website uses plain HTML, CSS, and JavaScript. It has no runtime framework, analytics, paid service, or secret key. All assets are served from this repository.

```sh
python3 scripts/build_site.py
python3 scripts/check_site.py
python3 -m http.server 8080 --directory already-clean
```

Open `http://localhost:8080`. The build reads recorded result files; it performs no new statistical estimation. GitHub Actions validates the inputs and site on pushes to `main`. GitHub Pages serves the committed `already-clean/` folder alongside the repository’s existing robot-control homepage. Changes to the walkthrough belong in `already-clean/index.html`, `already-clean/assets/site.css`, and `already-clean/assets/site.js`; data exports and download archives are generated by `scripts/build_site.py`.
